Latest Project

I’m currently working on a mobile app in Android Studio called CampusLink. The idea is to create a simple platform for university students to share notes, past papers, and quick updates in one clean space. I’m building it with a focus on clean UI design and efficient backend logic, making sure everything feels lightweight and fast. Right now, I’m working on user authentication, a basic upload system for PDFs, and a structured feed where students can post academic resources. I’m paying close attention to how the data flows between activities and how to keep the architecture organized so it scales properly as I add features like messaging and search.
